# Licenças de terceiros

O OpusSistem usa as bibliotecas abaixo, baixadas pelo Maven. Os textos completos das licenças acompanham cada
biblioteca. Esta lista é informativa; confira a licença de cada versão antes de redistribuir.

| Biblioteca | Uso | Licença |
|---|---|---|
| OpenJFX (JavaFX) | Interface gráfica | GPL v2 + Classpath Exception |
| MySQL Connector/J | Conexão JDBC com o MySQL | GPL v2 com FOSS License Exception |
| OpenPDF | Geração de PDF | LGPL 2.1 / MPL 2.0 |
| jsoup | Leitura do HTML do editor de texto | MIT |
| Gson | JSON (exportar/importar) | Apache 2.0 |
| JUnit 5 | Testes | EPL 2.0 |

## Fonte Inter (opcional, não incluída)

Se você adicionar os arquivos da fonte Inter em `src/main/resources/fonts/`, ela é licenciada sob a
**SIL Open Font License 1.1**; mantenha o texto da licença junto dos arquivos ao redistribuir.
